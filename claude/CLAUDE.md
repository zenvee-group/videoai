# Preferências do usuário

- Idioma: português do Brasil em todas as respostas.
- Edição de vídeo: usar SEMPRE a skill `editor-video-pt` (padrão da casa). Projetos ficam em
  `/home/user/videos/<projeto>/` (originais somente leitura → trabalho → previa → saida).
- Prioridades: processamento local, custo zero, privacidade, qualidade. Nunca enviar mídia
  para APIs/serviços externos, nem postar, sem pedido explícito.
- Pedir aprovação antes de: instalar algo, rodar script externo novo, alterar o ambiente,
  e antes de renderizar um corte (mostrar o plano primeiro).
- Não acessar nem pedir credenciais sem necessidade.
